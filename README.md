# Anime Fighters — Godot 4 Starter

A lightweight Godot 4 starter project for a landscape Android anime-inspired arena fighter.

## Included
- Six selectable fighter slots: Garou, Madara, Aizen, Guts, Gojo, Kokushibo.
- Random opponent selection (never the same as the selected fighter).
- Three arena themes: Valley of the End, Sokyoku Hill, and Monster Association.
- Landscape layout, basic touch buttons, health bars, simple attacks and guard.
- Low/medium-cost primitive 3D placeholder models and environment geometry.
- Android export preset and a GitHub Actions workflow for cloud APK export.

## Open and run
Open `project.godot` with Godot 4.3 or newer.

## Android APK from a phone
See `BUILD_ON_ANDROID_PHONE_FA.md`. The APK is not included in this archive; the cloud workflow must run successfully first.

## Important scope note
This is a playable prototype foundation, not a finished high-fidelity commercial game. Fighter meshes are colored primitive placeholders; arenas use simple geometry. Custom anime-accurate models, detailed environments, polished animation, sound, hit reactions, and device testing remain to be added. No copyrighted game/anime assets are included.
